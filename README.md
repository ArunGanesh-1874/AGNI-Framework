# AGNI: Adversarial Generation for Native Indian Language Texts

A linguistically-motivated black-box adversarial attack framework for code-mixed Indian-language NLP (Hinglish and Tamil-English).

## Overview
AGNI implements seven linguistically motivated perturbation types (P1–P7) and a combined module (PC). It is evaluated on two language pairs
(Hinglish, Tanglish), two tasks (sentiment, hate/offensive-language detection) and three victim models (XLM-R, MuRIL, mBERT), against four baselines
(TextFooler, DeepWordBug, Random, AdvCodeMix).

| Type | Description | Example |
|---|---|---|
| P1 | Phonetic variation | bhai -> bhay |
| P2 | Character-level | bahut -> baut |
| P3 | Cross-script | namaste -> नमस्ते |
| P4 | Transliteration variant | pyaar -> pyar |
| P5 | Morphological variation | achha -> acche |
| P6 | Code-switching | good -> achha |
| P7 | Hindi synonym | achha -> badhiya |
| PC | Combined perturbation | chain of the above on one token |

## Attack variants
- **AGNI-Full:** all types, budget beta = 0.60, similarity threshold tau = 0.75.
- **AGNI-Strict:** character-level noise restricted to non-target-language tokens, beta = 0.40.
- Baselines and the controlled comparison use beta = 0.40, tau = 0.80.

## Metric
AQI = ASR × AvgSim × (1 − AvgQ / Qmax). AvgSim is the mean LaBSE similarity over all attempted examples; Qmax = 99.3 (largest average query count over all 72 experiments).
For each method and language, AQI is computed from the averages of ASR, AvgSim and AvgQ over its experiments; "overall" is the mean of the two languages.

## Repository layout
- `code/` — attack framework (`modules_v2.py`, `search_v2.py`), experiment runners (`run_*.py`), training scripts (`train_*.py`), analysis scripts.
- `data/` — processed data and adversarial outputs.
- `human_eval/` — annotation sheets, responses and analysis (`analyze_human_eval.py`).
- `results/` — per-experiment summaries and analyses (see `results/README.md`).

## Reproducing the paper numbers
Scripts expect the server layout `/workspace/comixattack` (override with the `AGNI_BASE` environment variable where supported). Trained victim models are not included (see `.gitignore`); train them with `code/train_*.py`.

| Paper item | Script | Output |
|---|---|---|
| Main attack runs (Tables 2, 3) | `run_full_experiment_v4c.py` (Hinglish AGNI-Full), `run_tamil_experiment.py`, `run_full_experiment_v2.py` (Hinglish AGNI-Strict, output folder `comixattack_v3_full`), `run_tamil_strict_experiment_v2.py`, baselines: `run_deepwordbug_baseline.py`, `run_textfooler_baseline.py`, `run_random_baseline.py`, `run_advcodemix_baseline.py` (+ Tamil variants) | `results/<folder>/*_summary.json` |
| Per-experiment LaBSE similarity | `compute_labse_similarity_all.py` (needs corpora) | `results/labse_similarity_per_experiment.json` |
| AQI, Tables 2, 3, 6 | `build_tables.py` | `results/aqi_final_v2.json` |
| Controlled comparison (Table 5) | `run_controlled_experiment.py`, `run_controlled_hate_only.py`; matched-population version: `run_controlled_matched.py` | `results/comixattack_controlled*/` |
| Ablation (Sec 5.7) | `run_ablation.py` | `results/ablation/` |
| WER, perplexity | `compute_wer.py`, `compute_perplexity.py` | `results/wer_analysis.json`, `results/perplexity_analysis.json` |
| Human evaluation (Sec 5.5, Table 8) | `human_eval/analyze_human_eval.py` | `human_eval/human_eval_results.json` |

Quick check without a GPU: `python code/build_tables.py --base . --sim results/labse_similarity_per_experiment.json` regenerates the AQI tables from the committed summaries.

## Limitations
Human-evaluation agreement is near zero (Krippendorff's alpha), so the ratings are exploratory. Language-identification validation covers Hinglish only. The ablation covers one language, task and model.
